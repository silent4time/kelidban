# کلیدبان (Kelidban)

سرور صدور و تأیید لایسنس ربات‌ها (۱ تا ۱۲ ماه، قفل روی دامنه) با پنل مدیریت خصوصی.

**نسخه:** 2.0.1 — تغییرات در [CHANGELOG.md](CHANGELOG.md)

| مورد | مقدار |
|------|-------|
| مسیر نصب | `/home/kelidban` |
| دامنه | دامنهٔ سرور لایسنس شما (مثال: `https://license.example.com`؛ در ارتقا همان دامنهٔ قبلی می‌ماند) |
| تأیید ربات‌ها | `{دامنه}/api/verify.php` (در ارتقا بدون تغییر) |
| پنل مدیریت | آدرس مخفی؛ با `sudo kelidban url` ببینید |
| بکاپ‌ها | `/root/kelidban-backups` |

`config.php` و پوشهٔ `storage` (دیتابیس) هرگز در گیت نمی‌روند.

---

## نصب یا انتقال روی سرور (یک بار)

نصب‌کننده خودش تشخیص می‌دهد کدام حالت است:

| حالت | کی | چه می‌کند |
|------|----|-----------|
| **انتقال** | نسخهٔ قدیمی در `/home/license_server` هست | تنظیمات و دیتابیس را به `/home/kelidban` می‌برد، تنظیم آپاچی را عوض می‌کند، سایت را تست می‌کند و پوشهٔ قدیمی را با پسوند `.old-تاریخ` نگه می‌دارد |
| **آپدیت** | `/home/kelidban` از قبل هست | فقط کد را تازه می‌کند |
| **نصب تازه** | هیچ‌کدام نیست | آپاچی، PHP، SSL و همه‌چیز را راه می‌اندازد |

در هر سه حالت **قبل از هر تغییری** از کل پوشه بکاپ می‌گیرد و به `config.php`، دیتابیس و پوشهٔ پنل دست نمی‌زند. اگر بعد از انتقال سایت جواب ندهد، تنظیم آپاچی را خودکار برمی‌گرداند و چیزی از دست نمی‌رود.

### راهنمای نصب مصور

[راهنمای نصب کلیدبان (PDF)](docs/راهنمای-نصب-کلیدبان.pdf)

### نصب با یک دستور

```bash
curl -fsSL https://cdn.jsdelivr.net/gh/silent4time/kelidban@main/install.sh | sudo bash
```

اسکریپت اول `apt update` و `apt upgrade` را می‌زند، توکن گیت‌هاب را می‌پرسد، مخزن را می‌گیرد و بعد دامنه و بقیه را خودش می‌پرسد.

### مرحله ۱: گرفتن کد روی سرور

چون ریپو خصوصی است، یکی از این دو راه:

**راه الف: با git (پیشنهادی؛ آپدیت‌های بعدی یک‌خطی می‌شود)**

1. در GitHub بروید به Settings › Developer settings › Personal access tokens › **Fine-grained tokens** › Generate new token.
2. Repository access: فقط `kelidban`؛ Permissions › Contents: **Read-only**. توکن را کپی کنید.
3. روی سرور:

```bash
git clone https://github.com/silent4time/kelidban.git /opt/kelidban-src
```

نام کاربری `silent4time` و به‌جای رمز، همان توکن را بدهید.

**راه ب: با فایل zip**

در صفحهٔ ریپو در GitHub: Code › Download ZIP. فایل را با WinSCP یا هر برنامهٔ SFTP در `/root/kelidban.zip` بگذارید و:

```bash
unzip -o /root/kelidban.zip -d /opt && mv /opt/kelidban-main /opt/kelidban-src
```

### مرحله ۲: اجرای نصب‌کننده

```bash
sudo bash /opt/kelidban-src/install.sh
```

حالت را نشان می‌دهد و تأیید می‌گیرد. در پایان:

- اگر رمز پنل ضعیف یا تعیین‌نشده باشد، رمز تازه می‌پرسد (حداقل ۱۰ حرف؛ ۱۲ حرف به بالا پیشنهاد می‌شود).
- **آدرس خصوصی پنل** را چاپ می‌کند؛ مثل `https://license.example.com/kb-1a2b3c4d5e6f7a8b/`. این آدرس را در جای امنی ذخیره کنید (بوکمارک مرورگر). آدرس قدیمی `/admin/` دیگر وجود ندارد.

ربات‌ها هیچ تغییری لازم ندارند؛ همان آدرس `api/verify.php` کار می‌کند.

## فرمان‌های سرور

همه با `sudo` اجرا می‌شوند:

| فرمان | کار |
|-------|-----|
| `kelidban url` | نمایش آدرس خصوصی پنل |
| `kelidban password` | تعیین یا تغییر رمز پنل (همهٔ نشست‌های باز بسته می‌شوند) |
| `kelidban new-url` | ساخت آدرس تازه برای پنل؛ آدرس قبلی از کار می‌افتد |
| `kelidban unlock` | باز کردن قفل ورود (اگر خودتان قفل شدید) |
| `kelidban logout-all` | خارج کردن همهٔ نشست‌های باز پنل |
| `kelidban status` | نسخه، آدرس پنل، وضعیت رمز، تعداد لایسنس‌ها، آخرین ورود |
| `kelidban backup` | بکاپ فوری دیتابیس در `/root/kelidban-backups` |
| `kelidban update` | آپدیت از گیت |

**رمز را فراموش کردید؟** `sudo kelidban password`
**آدرس پنل یادتان رفت؟** `sudo kelidban url`
**قفل شدید؟** ۱۵ دقیقه صبر کنید یا `sudo kelidban unlock`

## امنیت پنل

- **آدرس مخفی:** پنل در پوشه‌ای با نام تصادفی است (`/kb-…/`)؛ آدرس‌های حدس‌زدنی مثل `/admin/` وجود ندارند و در صفحهٔ اصلی هم لینکی به پنل نیست.
- **رمز هش‌شده:** رمز در `config.php` نیست؛ فقط اثر آن (Argon2id) در دیتابیس ذخیره می‌شود. رمز متنی قدیمی هنگام انتقال خودکار هش و از `config.php` پاک می‌شود.
- **قفل ورود:** بعد از ۵ رمز اشتباه، آن IP برای ۱۵ دقیقه قفل می‌شود. اگر از IPهای مختلف در مجموع ۴۰ تلاش اشتباه شود، ورود برای همه بسته می‌شود تا با `sudo kelidban unlock` باز کنید.
- **CSRF:** همهٔ فرم‌ها توکن یک‌بارمصرف نشست دارند و درخواست از سایت دیگر رد می‌شود.
- **کوکی امن:** `Secure`، `HttpOnly`، `SameSite=Strict`، فقط برای مسیر پنل؛ شناسهٔ نشست بعد از ورود عوض می‌شود.
- **نشست:** بعد از ۳۰ دقیقه بی‌فعالیتی و حداکثر بعد از ۱۲ ساعت بسته می‌شود؛ تغییر مرورگر هم نشست را باطل می‌کند.
- **هدرهای امنیتی:** CSP سخت‌گیر، `X-Frame-Options: DENY`، `nosniff`، `Referrer-Policy`، `HSTS`، بدون `X-Powered-By`.
- **HTTPS اجباری:** پنل، صفحهٔ اصلی و صفحهٔ خرید روی http به https می‌روند. API ربات‌ها عمداً ریدایرکت نمی‌شود تا ربات‌ها از کار نیفتند.
- **API وردپرس:** فقط با کلید API ساخته‌شده در پنل (یا `api_token` در `config.php`)؛ رمز پنل دیگر به‌جای کلید پذیرفته نمی‌شود. ۱۰ تلاش اشتباه در ۱۵ دقیقه، آن IP را با کد 429 رد می‌کند.
- **صفحهٔ خرید:** توکن CSRF و حداکثر ۵ درخواست در ساعت از هر IP.

تنظیمات این بخش در `config.php` است (`login_max_attempts`، `login_lock_minutes`، `session_idle_minutes` و …). اگر جلوی سرور Cloudflare یا پراکسی دارید، `trust_proxy` را `true` کنید.

## اتصال افزونهٔ وردپرس

1. در پنل، کارت «اتصال وردپرس (کلید API)» › «ساخت کلید API» و کپی کلید (فقط یک بار نمایش داده می‌شود).
2. در وردپرس: «تنظیمات» › «سرور لایسنس» › «سرور لایسنس جداگانه»؛ آدرس `https://license.example.com` و همان کلید › «ذخیره و تست اتصال».

API مدیریت: `POST /api/manage.php` با بدنهٔ JSON (`action`) و هدر `Authorization: Bearer <key>`.
عملیات‌ها: `ping` · `stats` · `list` · `get` · `create` · `extend` · `revoke` · `domain` · `export` · `import`

## رفتار لایسنس

- انقضا ← `sales_ok=false` (ربات مشتری فقط فروش را متوقف می‌کند)
- حدود ۷ روز مانده به انقضا ← `warn=true`
- اگر این سرور قطع شود، ربات مشتری تا ۹۶ ساعت از آخرین تأیید موفق کار می‌کند
- کرون `/etc/cron.d/kelidban`: هر ۱۵ دقیقه بررسی سلامت (اطلاع به تلگرام/بله/واتساپ اگر در `config.php` پر شده باشد) و هر شب ساعت ۳:۳۰ بکاپ دیتابیس (۳۰ روز نگه داشته می‌شود)

## بازگردانی بکاپ

```bash
sudo cp /root/kelidban-backups/licenses_YYYYMMDD_HHMMSS.sqlite /home/kelidban/storage/licenses.sqlite
sudo rm -f /home/kelidban/storage/licenses.sqlite-wal /home/kelidban/storage/licenses.sqlite-shm
sudo chown www-data:www-data /home/kelidban/storage/licenses.sqlite
```

بکاپ کامل پوشه (قبل از هر نصب/آپدیت) هم به شکل `kelidban-تاریخ.tgz` در همان پوشه است.

## ساختار

```text
app/            پنل و صفحهٔ ورود (بیرون از public)
bin/kelidban    فرمان سرور
cron/           بررسی سلامت
lib/            هسته و لایهٔ امنیت
public/         ریشهٔ وب: صفحهٔ اصلی، buy/، api/، assets/ و پوشهٔ مخفی پنل kb-…
storage/        دیتابیس SQLite و نشست‌ها (فقط www-data)
install.sh      نصب، آپدیت، انتقال
```
